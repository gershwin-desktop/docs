# System Preferences

System Preferences provides a centralized location for configuring Gershwin and the underlying system. It uses a pluggable preference pane architecture.

## Preference panes

- **Appearance**: Color schemes and themes
- **Defaults**: System-wide application defaults
- **Displays**: Display configuration
- **Energy**: Power management
- **FileSystem**: Mounted volumes and filesystem settings
- **Fonts**: Font management
- **Internet**: Network and internet settings
- **Keyboard**: Keyboard layout and shortcuts
- **ModifierKeys**: Remap modifier keys
- **Mouse**: Mouse and trackpad settings
- **Sound**: Audio input and output
- **Themes**: Desktop theme configuration
- **TimeZone**: Date and time settings
- **Volumes**: Disk and storage management

## Location

`/Applications/SystemPreferences/SystemPreferences.app`
