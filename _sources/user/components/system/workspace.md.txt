# Workspace

Workspace is the file manager and desktop environment for Gershwin. It provides the desktop background, Dock, file browsing, and integration with application bundles.

## Features

- **Desktop**: Manages desktop icons, wallpapers, and the Dock
- **File browsing**: Navigate the filesystem with a Finder-like interface
- **.app bundle support**: Full support for application bundles as first-class citizens
- **Extensions**: Plugin system for extending functionality
- **Metadata**: Integrates with GSMetadata for file attributes

## Location

`/Applications/Workspace/Workspace.app`
