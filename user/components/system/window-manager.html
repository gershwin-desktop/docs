Window Manager

The Window Manager is the native X11 window manager for Gershwin. It manages window positioning, resizing, focus, compositing, and provides window switching.

Features

  • Window Overview: Bird’s-eye view of all open windows (Super+W)

  • Snapping: Snap windows to screen edges

  • Compositing: Hardware-accelerated compositing

  • EWMH compliance: Works with standard X11 window management protocols

  • Theming: Integrates with the GNUstep theme system

Keyboard shortcuts

Shortcut

Action

Super+W

Toggle window overview

Super+Left/Right

Snap window to left/right half

Super+Up

Maximize window

Alt+Tab

Cycle windows

Alt+~

Cycle windows of current app

Location

/Applications/WindowManager/WindowManager.app
